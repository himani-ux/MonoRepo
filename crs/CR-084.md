**What & why** - The Safety Dashboard is still too busy for office users, and the Auditor Bundle Export vessel filter is a free-text field even though users expect the same vessel dropdown pattern used elsewhere. This change makes `/safety/dashboard/` default to a quieter summary-first view and moves detailed analytics behind one details toggle, while `/safety/admin/auditor-export` loads active vessels into a dropdown for the vessel filter.

**Tier + triggers** - Tier 2. Triggers: changed screen state on the Safety Dashboard, changed Auditor Bundle Export filter control behavior, and frontend tests/docs updated for the changed UI contract.

**Domains touched** - Step 1 domains: Safety Dashboard presentation, dashboard advanced analytics visibility, Auditor Bundle Export filters, active vessel option source, frontend route tests, and maintain-mode documentation.

**Decisions** - D-MAINT-CR084: `/safety/dashboard/` defaults to the Safety score, current view context, period/vessel controls, and export controls only; repeat issues, top repeat causes, corrective-action age, Heinrich Ratio, and SOI Compliance % remain available behind **Show dashboard details**. Auditor Bundle Export uses a vessel dropdown populated from the existing `/api/safety/incidents/vessels/` vessel option endpoint instead of a free-text vessel filter.

**Doc cascade** - `safety_docsuite/IMPLEMENTATION_PLAN.md`, `safety_ssot/VIMS-SAFETY-MODULE-SSOT.md`, `safety_docsuite/PRD.md`, `safety_docsuite/APP_FLOW.md`, `safety_docsuite/USER_GUIDE.md`, and `safety_docsuite/VALIDATION_RULES.md` describe the quieter dashboard default and Auditor Bundle Export vessel dropdown. `safety_docsuite/BACKEND_STRUCTURE.md` unchanged because this uses the existing incident vessel-list endpoint and does not change backend routes or payload contracts. `Docs/progress.txt` records the change.

**Tests** - Update `psc-frontend/tests/frontend/safety/dashboard-route.test.tsx` for the hidden-by-default details panels and update `psc-frontend/tests/frontend/safety/auditor-export-route.test.tsx` for the loaded vessel dropdown.

**Fidelity check** - no deltas. The dashboard keeps existing data available on request while simplifying the default view, and the auditor export vessel filter now contains vessel dropdown options.

**Exemptions** - none.
