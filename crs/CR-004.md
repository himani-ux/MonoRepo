# CR-004 - Injury Dropdown Master Table

## What & why

Incident Phase 1 injury dropdowns for Nature of Injury, Source of Injury, and Affected Areas of the Body now come from a DB master table with UUID primary keys. This replaces the temporary frontend-only dropdown lists so the values can be managed as master data.

## Tier + triggers

Tier 3 - structural. Triggers: new DB table, new migration, new reference endpoint, changed Phase 1 dropdown data source, and canonical docs update.

## Domains touched

Data model, DB migration/deployment notes, reference API, frontend form behavior, UI flow/screen state, validation documentation, SSOT, and implementation plan.

## Decisions

No new SSOT decision ID assigned. CR-004 supersedes CR-003's "no DB migration" statement. `vims_safety_injury_dropdown_option` owns the dropdown labels; `vims_safety_external_party_injury` continues to store the selected label or typed Other value.
