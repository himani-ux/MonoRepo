**What & why**
Fix External Audit registration so users who are allowed to register an external audit can load and select active External Audit Organisation rows. The org master maintenance permission should still control creating or editing organisations, but registration users need read access to the active list so the required organisation field is not disabled.

**Tier + triggers**
Tier 2 - small feature / behavior change. Triggers: changed role permission behavior for reading External Audit Organisation master rows during registration, and bugfix to the External Audit registration screen validation feedback.

**Domains touched**
Domain 2 screen/state coverage: Audit External Audit Registration (`SCR-AUD-8`).
Domain 5 roles/permissions: External Audit Organisation master list read access for external audit registration.
Domain 7 field map / validation: `external_audit_org_id` required feedback on External Audit registration.

**Decisions**
Accepted default: allow users with External Audit registration permission to `GET` active External Audit Organisation rows.
Accepted default: keep create/update/detail access for External Audit Organisation master maintenance restricted to the manage-org permission.
Accepted default: when the organisation list cannot be loaded or has no rows, keep the selector disabled but show the same field-level required message area and a clear load/no-data message.
