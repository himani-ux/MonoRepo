# CR-037 - Remove Duplicate Phase Headers

## What & why

Incident phase tabs already show the current phase number and phase name. The phase content area should not repeat the same phase number/name as extra header information inside each phase page. This change removes redundant in-page phase-identification headers while keeping the phase tabs, workflow, forms, and functional section headings intact.

## Tier + triggers

Tier 2 - small behavior/UI change. Triggers: changed Incident phase screen state and user-facing copy/layout cleanup. No database, endpoint, role, or validation change is planned.

## Domains touched

Step 1 domains to verify: Incident phase workspace screen states, phase tab/header layout, frontend regression tests, and current safety documentation.

## Decisions

- `D-MAINT-CR037` - incident phase tabs are the single visible phase-number/name indicator; in-page duplicate phase headers are removed where they only repeat tab information.
