# CR-179 - Audit Resolution Package Implementation

## What & why

Implement the approved Audit resolution package dated 2026-09-02 so the maintained system matches the registered D-AUDRS-140..149 decisions: Audit finding capture, Audit CAR numbering, NC/OBS closure presentation, audit navigation, OPM F 713 generation/display, actor attribution, and digital-signature behavior must align with the approved resolution and reference mocks/templates.

## Tier + triggers

Tier 3 - structural. Triggers: changed Audit workflow states and actors, changed role-permission behavior, changed frontend screen states, changed endpoint contracts, cross-module CAR/physical-verification behavior, PDF generator additions, and additive schema/data-contract requirements from D-AUDRS-149.

## Domains touched

Domain 12 Audit module workflow and personas; Domain 13 quality/test gates; Domain 14 release/deployment documentation where generated forms and release behavior are affected.

## Decisions

No new local decision is introduced by this CR. It implements registered decisions D-AUDRS-140, D-AUDRS-141, D-AUDRS-142, D-AUDRS-143, D-AUDRS-144, D-AUDRS-145, D-AUDRS-146, D-AUDRS-147, D-AUDRS-148, and D-AUDRS-149 from the 2026-09-02 resolution package. Where section 9 of the resolution conflicts with earlier section 2 wording, section 9 governs.

## Fidelity check

Implemented in this safe pass:

- D-AUDRS-140 - finding-level objective-evidence uploads are accepted in the Create Audit Finding multipart payload and stored as `AuditAttachment` category `FINDING_OBJECTIVE_EVIDENCE`; typed objective evidence remains mandatory.
- D-AUDRS-141 - PSC DefCode and Action Code are removed from Audit finding UI/API input; bridge deficiencies use sentinel DefCode `00000` and null Action Code; finding target closure date is collected at raise time.
- D-AUDRS-142 - Audit CAR numbers are generated as `{SCOPE}-AUDIT-{YYYY}-{NNN}` and PSC CAR numbering remains separate.
- D-AUDRS-145/D-AUDRS-146 - NC has one dense route/presentation, OBS has one wizard route/presentation, and legacy route URLs resolve to the approved presentation instead of exposing a user mode choice.
- D-AUDRS-145 - NC Part C uses PSC CAR CLC item selections plus a root-cause summary.
- D-AUDRS-140 - duplicate editable Certificates at Risk controls in NC Parts E and F no longer overwrite the finding-level certificate scope.
- D-084/D-AUDRS-149 UI refinement - Register Audit is consolidated behind an Internal / External chooser and the separate sidebar External Audit entry is removed.
- D-AUDRS-144 display slice - Audit Plan Register OPM F 713 column renders readable reference/date text instead of raw stored values.

Fidelity deltas intentionally left for a later, schema/PDF-focused pass:

- D-AUDRS-140 final storage convention proposal remains pending; this pass uses existing `AuditAttachment` storage.
- D-AUDRS-147 automatic `psc_physical_verification` creation/writeback from `LEAD_AUDITOR_CLOSED` was not implemented in this slice.
- D-AUDRS-148 generated PDF regeneration with D-261 QR/hash footer and signature blocks was not implemented in this slice.
- D-AUDRS-149 additive columns/rename (`master_audit_plan.extension_sought_date`, `plan_ref`, `completed_at`, `completed_by`, and `audit_signature.dpa_close_at`) were not implemented in this slice.
