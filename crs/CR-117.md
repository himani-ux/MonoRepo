**What & why** - Ship users should be able to view the latest uploaded class status PDF as soon as office uploads it, without waiting for office to send a reconciliation message. The vessel certificate dashboard already knows the latest class snapshot; this change exposes a direct class status PDF action there and keeps vessel access scoped to the user's own vessel.

**Tier + triggers** - Tier 2 small feature/behavior change. Triggers: new vessel-side screen state/action, changed class snapshot PDF access path, and new regression coverage.

**Domains touched** - Step 1 domains: Certs vessel dashboard, class snapshot PDF access, frontend/backend regression tests, and Certs documentation.

**Decisions** - No new SSOT decision expected. Accepted default: vessel dashboard shows the latest non-superseded class snapshot PDF when a snapshot exists; the same secure `/api/certs/class-snapshots/<id>/pdf/view/` endpoint is reused with own-vessel access checks.
