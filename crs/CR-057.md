**Tier + triggers** - Tier 3. Triggers: changed validation rule, changed backend database constraint/API behavior, changed frontend action-screen state, and superseded the original `IMPLEMENTATION_PLAN` one-row-per-tier cardinality lock.

The old one-active-recommendation-per-tier database/API guard is removed.
