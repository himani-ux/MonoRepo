# CR-020 - Remove Evidence Notes and Current Scope UI

## What & why

The incident UI should be less cluttered for vessel users. Remove the user-facing Evidence Notes section from the Phase 2 RCA screen and remove the Current Scope card from the main incident list page while keeping the existing incident workflow, saved data, API contracts, and permissions unchanged.

## Tier + triggers

Tier 2 - small behavior/screen-state change. Triggers: changed screen state on Incident Phase 2 and changed screen state on the incident list page.

## Domains touched

Step 1 domains to verify: Incident Phase 2 RCA UI, incident list UI, frontend regression tests, and current safety user documentation.

## Decisions

Accepted default: remove only the visible Evidence Notes and Current Scope UI elements. Existing evidence-note data handling, incident filtering, vessel scope behavior, API contracts, and workflow gating remain unchanged.
