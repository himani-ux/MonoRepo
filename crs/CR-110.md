**What & why** - Print this vessel and Share Bundle should not ask the user to pick a vessel again when the vessel is already known from the office-side vessel page or the ship-side logged-in vessel. This change removes the vessel dropdowns from those vessel-scoped actions and keeps certificate selection as the main choice, with clearer category grouping so users can find certificates without remembering IDs.

**Tier + triggers** - Tier 2. Trigger: changed screen behavior/screen state in the Certs print/share workflow and changed picker validation behavior. No new table, migration, endpoint, role permission, or external integration is expected.

**Domains touched** - Certs print/export workflow, vessel dashboard action flow, certificate picker UI, user-facing documentation, frontend regression tests.

**Decisions** - Accepted default: vessel context is authoritative for vessel-scoped print/share actions. Office users enter from a selected vessel, and ship-side users use the logged-in vessel, so the UI must not show a vessel dropdown for those actions. Certificate choices remain selectable and should be grouped by user-friendly categories.
