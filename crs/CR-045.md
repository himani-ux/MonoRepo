# CR-045 - Open Phase 5 Witness Statement directly

## What & why
The Phase 5 Evidence workspace currently makes users click **Witness Statement** and then click a second **Open Witness Statement** link. The Witness Statement card should navigate directly to the witness statement page on the first click so the evidence support flow is simpler and matches the current intended UI.

## Tier + triggers
Tier 2 - small behavior change. Trigger: changed screen interaction/screen state for the Phase 5 Evidence supporting Witness Statement entry point.

## Domains touched
Step 1 Domains 2 and 8:
- Domain 2: Phase 5 Evidence UI interaction and user-facing navigation wording.
- Domain 8: frontend regression coverage for direct Witness Statement navigation.

## Decisions
- D-MAINT-CR045 accepted user direction: the Witness Statement card in Phase 5 must navigate directly to the witness statement page; no intermediate **Open Witness Statement** action is shown.
