**What & why**

Testing the Certs catalog Add row path showed the frontend still defaulted new rows to `master_only`, and the backend serializer accepted that value. This would allow newly added certificate rows to drift from D-CERT-199, where all active catalog rows must be `all_ranks_with_approval`.

**Tier + triggers**

Tier 2 - small behavior change. Triggers: changed validation rule and changed screen default for Certs catalog row creation.

**Domains touched**

Step 1 domains: catalog metadata, RBAC and approval workflow, user guidance.

**Decisions**

No new decision. This implements existing D-CERT-199 for newly added or edited catalog rows.
