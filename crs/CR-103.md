**What & why**
The Certs class-status snapshot fallback OCR currently uses Tesseract through `pytesseract`. This change replaces that fallback OCR engine with PaddleOCR to improve recognition accuracy on image-only class-status PDFs while keeping the same upload, parser, and reconciliation workflow.

**Tier + triggers**
Tier 2 - small behavior change. Triggers: new/changed non-patch OCR dependency and changed Certs document-processing behavior.

**Domains touched**
Step 1 domains: Certs class snapshot parser, Certs OCR dependency usage, Certs reconciliation upload workflow, Certs backend documentation, Certs user guidance, Certs tests.

**Decisions**
Accepted default: keep `pdfplumber` text extraction as the primary class snapshot path and run PaddleOCR only when the whole PDF exposes no text layer.

Accepted default: preserve the existing normalized parser payload, parser version shape, upload response behavior, and reconciliation engine contract. PaddleOCR returns text to the same NK/KR/BV parser modules.

Accepted default: do not change the visible UI design. Existing user wording may continue to say OCR fallback without naming the OCR engine.
