**What & why**
Certs users need a manual correction path when OCR reads certificate metadata incorrectly. This change adds an Edit action on the tracked-item metadata panel so permitted users can correct certificate number, issuing authority, place of issue, issue date, and expiry date without re-uploading the certificate.

**Tier + triggers**
Tier 2 - small behavior change. Triggers: new screen state and changed manual correction workflow using the existing tracked-item update contract.

**Domains touched**
Step 1 domains touched: Certs tracked-item detail UI, Certs tracked-item API usage, Certs documentation.

**Decisions**
No new SSOT decision planned. Accepted default: reuse the existing tracked-item update endpoint and audit trail instead of adding a separate OCR-correction endpoint.
