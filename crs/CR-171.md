**What & why**
Clean up External Audit registration so users link certificates through a readable selector instead of manually entering comma-separated certificate UUIDs. Review the `Report Reference` requirement at the same time because users should only be forced to enter business-visible information that is actually needed for audit traceability.

**Tier + triggers**
Tier 2 - small feature / behavior change. Triggers: changed External Audit registration screen state, changed frontend validation/submission behavior for linked certificates, and possible validation copy/requirement adjustment for report reference.

**Domains touched**
Domain 2 screen/state coverage: Audit External Audit Registration (`SCR-AUD-8`).
Domain 7 field map / validation: external audit report reference and linked certificate IDs (`FEAT-AUD-602`, `FEAT-AUD-603`).

**Decisions**
Accepted default: replace the visible `Linked Certificate UUIDs` text field with a readable `Linked Certificates` selector populated from existing Certs tracked items for the selected vessel.
Accepted default: keep `linked_cert_ids` as the submitted API field; UUIDs remain internal values selected by the UI, not typed by users.
Accepted default: make External Audit `Report Reference` optional in frontend validation because backend registration already accepts blank values and stores them as an empty string.
