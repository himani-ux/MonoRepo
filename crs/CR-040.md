# CR-040 - Add edit controls for saved RCA causes

## What & why
Saved Incident RCA causes currently appear as read-only cards even though the backend update endpoint allows editing before office approval. Users need a clear Edit action on each saved Immediate Cause and Root Cause so they can correct cause factor, selected cause, Other text, and reason without adding duplicate causes.

## Tier + triggers
Tier 2 - small behavior/UI change. Triggers: new Incident Phase 2 RCA screen state for editing existing saved cause cards. No database, endpoint, dependency, or role model change is planned.

## Domains touched
Step 1 Domains 2, 5, and 8:
- Domain 2: Incident Phase 2 RCA screen state and saved-cause card actions.
- Domain 5: validation/edit behavior for existing cause updates.
- Domain 8: frontend regression tests for editing saved RCA causes.

## Decisions
- D-MAINT-CR040 accepted default: each saved Immediate Cause and Root Cause card exposes an Edit action for authorized RCA users while the incident remains editable.
- D-MAINT-CR040 accepted default: editing uses the existing cause update endpoint and must update the existing card instead of creating a duplicate cause.
