# CR-021 - Remove Missing Vessel Incident Type

## What & why

The Incident Type dropdown should no longer offer `Missing Vessel`, and the incident-type master data should no longer expose that option for new incident reporting. Existing incident records that may already reference the old value must remain readable; the change applies to future selection and active master data only.

## Tier + triggers

Tier 3 - structural Maintain Mode change. Triggers: changed incident type master data, changed Incident Phase 1 dropdown options, and data migration touching existing master table data.

## Domains touched

Step 1 domains to verify: Incident Phase 1 report form, incident type master data, incident serializer/API contract compatibility, migrations/seed data, frontend regression tests, backend regression tests, and canonical safety documentation.

## Decisions

Accepted default: remove or deactivate only the `Missing Vessel` incident type option for new incident creation. Existing incident records remain readable and are not rewritten.
