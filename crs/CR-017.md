# CR-017 - Phase 4 Save Acknowledgement and Scroll

## What & why

Phase 4 users need clear confirmation after saving evidence or witness-note data, and the screen should move to the saved content so the user can immediately verify what was saved. This change adds a success acknowledgement and scroll-to-saved-content behavior for the Phase 4 Documents/Witness Notes save flows without changing backend contracts or workflow transitions.

## Tier + triggers

Tier 2 - small behavior change. Triggers: new screen state after save and changed frontend interaction behavior. No new DB column, endpoint, role permission, external integration, or validation rule is planned.

## Domains touched

Step 1 domains to verify: Incident Phase 4 UI/screen state, evidence document attachment save flow, witness notes save flow, frontend tests, and current user documentation.

## Decisions

No new SSOT decision expected. Default accepted: show a short inline success message after save and scroll to the saved content area, because that directly addresses the usability issue without changing workflow or persisted data.
