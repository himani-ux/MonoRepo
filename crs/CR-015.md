# CR-015 - Remove Phase 4 Evidence Check UI

## What & why

Phase 4 should no longer show the Evidence Check tool because the Safety evidence workflow has been simplified to user-added document attachments, title, and description. This change removes the confusing Evidence Check surface from Phase 4 while preserving existing backend data and legacy compatibility so older records do not break.

## Tier + triggers

Tier 3 - structural Maintain Mode change. Triggers: changed Safety screen state and contradiction of canonical SSOT/APP_FLOW/PRD/VALIDATION statements that still described Evidence Matrix/Evidence Check as a current Phase 4 supporting tool and Phase 5 bias guard.

## Domains touched

Step 1 domains to verify: Incident Phase 4 UI/screen state, Incident evidence routing, validation/docs wording, tests, and canonical safety documentation.

## Decisions

New SSOT decision `D-MAINT-CR015`: remove Evidence Check/Evidence Matrix from the current user-facing Phase 4 workspace and Phase 4 frontend route tree. Legacy evidence-matrix APIs, schemas, and stored data remain compatibility-only and are not deleted in this change. This supersedes `D-DNV-07` and `D-DNV-11 #4` for current user-facing Phase 4/5 evidence-matrix enforcement only.
