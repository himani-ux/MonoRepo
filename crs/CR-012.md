**What & why**
Incident evidence capture will be simplified from multiple category tabs into one document-oriented evidence section. Users will add as many evidence documents as needed, each with a title, description, and attachment, so the screen is easier to understand and does not force users to choose between People, Place, Equipment, and Photos/Files categories.

**Tier + triggers**
Tier 3. Triggered by changed incident screen state, changed evidence workflow behavior, and superseding existing canonical documentation that described category-based evidence tabs.

**Domains touched**
1. Incident evidence capture
2. Incident attachment upload
3. Incident phase transition gate
4. Incident PDF evidence output
5. Incident workflow documentation

**Decisions**
1. Replace category-tab evidence capture with a single Documents evidence list.
2. Keep the existing evidence storage tables and attachment upload API unless implementation proves a schema change is required.
3. Store each simplified evidence row as a document item with `title`, `description`, and attachment metadata.
4. Treat the simplified document list as satisfying the evidence capture requirement; no separate People, Place, Equipment, or Photos/Files categories are required.
