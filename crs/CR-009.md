**What & why**
Incident PDF export currently downloads the full report without asking the user what to include. The requested change adds a default-selected checklist before export so users can print only Summary, Reporter Details, Injury Details, Estimated Cost, Root Cause, Evidence (Documents), Corrective / Preventive Actions, Lessons Learned, and Signature.

**Tier + triggers**
Tier 2. Triggered by a new PDF export screen state and a changed incident PDF export request contract.

**Domains touched**
1. Incident PDF export UI
2. Incident PDF download API contract
3. Incident PDF rendering/template
4. Incident PDF regression tests

**Decisions**
1. Add a `sections` query parameter to incident PDF export/download endpoints.
2. Default all printable section checkboxes to selected.
3. Treat an omitted or empty `sections` query as "print all allowed sections" for backward compatibility.
4. Keep the report title at the top of every exported PDF even when Summary is not selected.

**Doc cascade**
- `safety_docsuite/APP_FLOW.md` - document the incident PDF export checklist and selected-section request behavior.
- `safety_docsuite/BACKEND_STRUCTURE.md` - document the incident PDF `sections` query parameter.
- `safety_docsuite/USER_GUIDE.md` - document how users choose PDF sections before printing.

**Tests**
Added/adjusted frontend route coverage for the default-selected checklist and backend PDF regression coverage for selected-section filtering.
