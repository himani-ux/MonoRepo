**What & why** - The Audit Qualified Auditors form allowed free typing for `Qualifying Body`, which can create inconsistent values such as `KSM`, `KSM Academy`, or spelling variants for the same certifying source. It also exposed `Certificate Attachment ID`, a backend UUID reference that users should not manually type. This change makes `Qualifying Body` a controlled dropdown of approved common bodies and removes the manual attachment UUID field from the screen while preserving the existing database columns and API contract.

**Tier + triggers** - Tier 2. Triggers: changed frontend screen state and changed frontend input behavior for Audit Qualified Auditors maintenance. No new endpoint, table, migration, role permission, external integration, or dependency is planned.

**Domains touched** - Step 1 domains: Audit master-data maintenance; qualified-auditor qualification evidence; Audit user guidance.

**Decisions** - D-MAINT-CR159: `Qualifying Body` is selected from a controlled frontend list of common internal and external auditor-qualification bodies. The saved value remains text in `master_audit_qualified_auditor.qualifying_body`. Existing uncommon saved values are still displayed as a preserved dropdown option while editing so data is not lost. `Certificate Attachment ID` is not shown on the maintenance form because it is a technical UUID reference, not a user-entered certificate number.

**Doc cascade** - `audit_docsuite/GAPS_2.md` updated to record that Qualified Auditors now uses a controlled `Qualifying Body` dropdown. `audit_docsuite/resolution response.md` updated to reflect the active local behavior. `audit_docsuite/USER_GUIDE.md` updated to explain the dropdown and removal of manual attachment UUID entry. `Docs/progress.txt` updated. `audit_docsuite/BACKEND_STRUCTURE.md` unchanged because no API or database contract changed.

**Tests** - Added frontend regression coverage that the Qualified Auditors form renders `Qualifying Body` as a dropdown, saves the selected value, and does not render the manual Certificate Attachment ID input.

**Fidelity check** - no deltas.

**Exemptions** - none.
