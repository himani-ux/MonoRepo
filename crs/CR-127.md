# CR-127 - Certs Reconciliation Vessel Filter

## What & why

Add a vessel filter to the Class Reconciliation runs list so office users can narrow reconciliation history by vessel name. The upload form already selects a vessel, but the runs table currently has no matching filter, which makes it harder to review vessel-specific class snapshot activity.

## Tier + triggers

Tier 2 - small behavior/UI change.

Triggers: new screen state and changed list query behavior for reconciliation runs.

## Domains touched

Step 1 domains touched: Certs reconciliation workflow, Certs office review/search experience.

Mini-interrogation:
- Who uses it: office-side Certs users reviewing class status snapshot reconciliation runs.
- Current issue: runs list is not vessel-filtered from the page, even though upload is vessel-specific.
- Accepted default: use the existing vessel options and show an "All vessels" filter option.
- Accepted default: keep upload behavior unchanged.

## Decisions

No new SSOT decision. This is a local filtering addition to an existing list.

## Doc cascade

Docs not updated: canonical Certs workflow docs unchanged because upload/reconciliation lifecycle is unchanged; this only adds a filter control to the existing review screen.
