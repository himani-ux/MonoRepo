**What & why**
Remove Linked Certificates from External Audit registration because users should not have to decide certificate relationships while registering an external audit report. The screen should capture the report, audit context, and findings workflow inputs only; certificate linkage remains a backend-compatible optional field for older clients but is no longer exposed or submitted by this UI.

**Tier + triggers**
Tier 2 - small feature / behavior change. Triggers: changed External Audit registration screen state and changed frontend submission behavior by removing certificate linking from the form payload.

**Domains touched**
Domain 2 screen/state coverage: Audit External Audit Registration (`SCR-AUD-8`).
Domain 7 field map / validation: external audit linked certificate IDs (`FEAT-AUD-603`).

**Decisions**
Accepted default: remove the visible `Linked Certificates` selector from External Audit registration.
Accepted default: stop submitting `linked_cert_ids` from the External Audit registration UI; keep backend serializer compatibility for the optional field so older clients do not break.
