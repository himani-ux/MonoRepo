# CR-134 - PSC CAR Vessel-Aware Numbering

**What & why** - Future PSC CAR numbers must include the vessel code so users can identify which vessel a CAR belongs to from the number itself. Existing CAR numbers must remain unchanged, and this change must not modify database schema or historical records.

**Tier + triggers** - Tier 2. Trigger: changed business behavior for generated CAR numbers.

**Domains touched** - Step 1 domains: PSC inspection, deficiency, CAR lifecycle, reports/search display, audit/activity text.

**Decisions** - New CARs created from deficiencies use `<VESSEL_CODE>-PSC-<YEAR>-<NNN>`, with sequence scoped to the same vessel and year. Historical CAR numbers are not changed. No database datatype or schema changes are included. If a vessel code is missing, the generator uses a deterministic short vessel fallback inside the existing 20-character column limit rather than changing schema. CAR creation retries on unique-number collision so concurrent same-vessel creation can regenerate before failing.
