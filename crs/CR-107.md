**What & why** - The Certs Print Builder and Share Bundle picker dropdowns need a clearer visual surface and better bulk-selection support. This change makes the dropdown panels opaque and structured, adds a Select all / Clear all action, and groups certificate choices so users can scan certificates by vessel and section instead of reading one long mixed list.

**Tier + triggers** - Tier 2. Triggers: changed screen control state, added picker bulk action, and changed certificate dropdown presentation/grouping on existing Certs print/share screens.

**Domains touched** - Certs print/share workflow, frontend picker controls, Certs certificate selection data flow, user-facing Certs documentation.

**Decisions** - No new SSOT decision. Accepted defaults: keep the existing print/share API payload shape, apply the improved dropdown behavior to both Print Builder and Share Bundle, group certificate choices by vessel and section when those fields are available, and keep all IDs hidden from normal users.

**Doc cascade** - `certs_docsuite/APP_FLOW.md` updated to describe grouped certificate dropdowns and Select all / Clear all behavior. `certs_docsuite/USER_GUIDE.md` updated with the user-facing picker workflow. `certs_docsuite/BACKEND_STRUCTURE.md` unchanged because no API endpoint or payload contract is changed.

**Tests** - Frontend route validation covers the opaque dropdown styling, Select all / Clear all controls, and grouped certificate dropdown behavior.

**Fidelity check** - no deltas. The implemented dropdown panels are explicitly opaque, both vessel and certificate pickers support Select all / Clear all against visible choices, certificate choices are grouped by vessel and section when available, IDs remain hidden from normal users, and the print/share API payload shape is unchanged.

**Exemptions** - none
