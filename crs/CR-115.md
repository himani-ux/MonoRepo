This change studies the provided KR, NK, and BV real reports, tightens parser rules per society, and surfaces parsed condition items on the existing reconciliation review page without changing unrelated UI.

**Tier + triggers** - Tier 2 small feature/behavior change. Triggers: changed parser validation behavior, changed existing API payload contents, changed Class Reconciliation review screen state, and new regression coverage.

**Decisions** - No new SSOT decision expected. Accepted default: class status freshness is derived from the printed/generated date extracted from the PDF; if the parser cannot read that date, upload/reparse records parser failure instead of falling back to upload time.
