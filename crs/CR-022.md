# CR-022 - Save Acknowledgement and Scroll Feedback

## What & why

Users need clear confirmation that their incident inputs were saved and should be taken to the saved content immediately after saving. Add success messages and automatic scroll-to-saved-content behavior when saving RCA causes, Next Actions entries including preventive actions, and Phase 4 document attachments. Keep existing API payloads, workflow transitions, and stored data unchanged.

## Tier + triggers

Tier 2 - small behavior/screen-state change. Triggers: changed screen state and interaction behavior on Incident Phase 2 RCA, Incident Phase 3 Next Actions, and Incident Phase 4 Documents.

## Domains touched

Step 1 domains to verify: Incident RCA UI, Incident Next Actions UI, Incident Documents UI, save acknowledgement wording, auto-scroll behavior, frontend regression tests, and current safety user documentation.

## Decisions

Accepted default: each successful save shows a user-facing success message and scrolls to the area where the saved item is visible. Existing backend contracts, validation rules, workflow transitions, and persistence remain unchanged.
