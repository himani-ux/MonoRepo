# CR-002 - Crew Injury Capture

## What & why

Incident Phase 1 injury capture is expanded from non-crew-only to crew-or-non-crew. Non-crew keeps the existing fields. Crew injury adds rank, age, vessel/location details, investigation narrative, OCIMF injury classification flags, and estimated cost fields.

## Tier + triggers

Tier 3 - structural. Triggers: migration touching existing table, new DB columns, changed Phase 1 screen state, changed API payload contract, and canonical docs update.

## Domains touched

UI flow/screen states, backend data layer, API serializers, field map/data model, validation rules, DB deployment notes, and canonical safety documentation.

## Decisions

No new SSOT decision ID assigned. Existing `vims_safety_external_party_injury` remains the physical table for compatibility, but the functional scope is now "injury record" with `injured_person_type` distinguishing `CREW` from `NON_CREW`.
