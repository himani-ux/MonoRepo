**What & why**
The incident PDF currently repeats the root-cause heading for every cause record in the same causal layer, which makes the report noisy and hard to scan. The requested change groups multiple causes within the same category into a single numbered box and improves the overall PDF print layout so the report reads more like a polished document and less like a raw dump.

**Tier + triggers**
Tier 2. Triggered by a changed screen state / PDF layout behavior and a changed report presentation contract.

**Domains touched**
1. Safety PDF rendering
2. Safety PDF template styling
3. Safety PDF regression tests

**Decisions**
1. Group `IncidentCauseTag` rows by `causal_layer` in the root-cause section.
2. Render multiple causes in a category as numbered items inside one block instead of repeating the same heading.
3. Keep the existing report section order and titles unless the layout change requires a minor wording cleanup.

none - no canonical document currently describes the PDF block layout at this level of detail.
