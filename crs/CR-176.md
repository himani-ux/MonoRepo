**What & why** - Audit registration should make vessel attendee entry easier by offering the top shipboard ranks as selectable personnel when the audit target is a vessel. The user should be able to choose the person from the Name control and have the corresponding rank filled automatically. This change also corrects three user-facing audit labels so CAR and follow-up wording is clear.

**Tier + triggers** - Tier 2. Triggers: changed Audit registration screen state/behavior and a compatible read-contract extension on the existing Audit vessel option response for vessel personnel metadata. No database schema change, migration, new endpoint, new role permission, external integration, or dependency was introduced.

**Domains touched** - Step 1 domains: Audit registration/personnel attendance; Audit detail verification labels; Audit NC closure effectiveness-review labels; Audit user guidance.

**Decisions** - D-MAINT-CR176: for vessel audits, populate Personnel Present name choices from the top shipboard ranks in this order: Master, Chief Officer/CO, Chief Engineer/CE, and Second Engineer/2E. Selecting a listed person fills the adjacent rank field while still allowing manual attendee entry when personnel data is unavailable.
