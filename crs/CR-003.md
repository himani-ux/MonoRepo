# CR-003 - Injury Dropdown Lists

## What & why

Incident Phase 1 crew injury now uses fixed dropdowns for Nature of Injury, Source of Injury, and Affected Areas of the Body. Each dropdown includes `Other (specify)` so users can enter a value when the list does not cover the case.

## Tier + triggers

Tier 2 - small behavior change. Triggers: changed Phase 1 screen state and changed validation/documented field behavior. No DB column or table change is required.

## Domains touched

UI flow/screen states, frontend form behavior, validation rules, user guidance, and deployment notes.

## Decisions

No new SSOT decision ID assigned. The selected dropdown value or typed `Other (specify)` value is stored in the existing text field (`nature_of_injury`, `source_of_injury`, or `affected_body_areas`) to avoid unnecessary schema changes.
