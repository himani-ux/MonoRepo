# CR-006 - Cleaner Evidence Workspace

## What & why

The evidence workspace felt crowded because evidence categories, uploads, witness notes, matrix checks, urgent tasks, and supporting panels were all presented with equal weight. This change keeps the same backend data and routes but makes the default Phase 4 screen simpler: users first choose the evidence type, add a short note, and upload files. Advanced tools are moved into collapsed sections so they are available without making the main screen hectic.

## Tier + triggers

Tier 2 - small behavior/UI change. Trigger: changed screen state and user-facing layout for the Incident Phase 4 evidence workspace.

## Domains touched
