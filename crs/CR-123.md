**What & why** - Change Certs print/share selection from individual certificate rows to certificate sections. Print certs status now uses a single section dropdown with "All sections"; Share Bundle now uses a section multi-select with Select all / Clear all. This keeps the workflow usable for vessels with hundreds of certificates and avoids asking users to pick each certificate one by one.

**Tier + triggers** - Tier 3. Triggers: changed screen state, changed selection rule, changed share-bundle request validation, and contradiction with D-CERT-208/D-CERT-209 text that allowed choosing an individual certificate.

**Domains touched** - Step 1 domains: Certs print workflow, Certs share-bundle workflow, share-bundle API validation, print artifact payload, frontend tests, backend serializer tests, Certs SSOT/docsuite.

**Decisions** - D-CERT-210 supersedes D-CERT-208/D-CERT-209 only for the Certificate List contents and Share Bundle selection contents. Users select certificate sections, not individual certificates, in the normal print/share screens. Backend-compatible custom certificate ID payloads remain accepted for existing integrations/history.
