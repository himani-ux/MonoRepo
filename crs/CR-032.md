# CR-032 - Clean Phase 1 Office, Location, Weather Layout

## What & why

The Incident Phase 1 form needs simpler user-facing wording and fewer fields. Office communication labels should say "informed" instead of "told"; WhatsApp should no longer be offered as an office communication mode; Last Port should be removed from the visible form; Weather Condition should no longer show ice-condition fields; and Latitude/Longitude should sit on one horizontal row with Shore Assistance shifted after them.

## Tier + triggers

Tier 3 - structural Maintain Mode change. Triggers: changed Incident Phase 1 screen state, changed dropdown option visibility, changed frontend payload behavior for hidden fields, and supersession of prior canonical CR-024/SSOT statements that made Last Port a current visible Phase 1 context field. No DB migration is planned because the existing columns remain compatibility storage for older records.

## Domains touched

Step 1 domains to verify: Incident Phase 1 UI/screen state, office-notification dropdown labels/options, reporting-context field placement, weather-condition field visibility, frontend schema/payload compatibility, frontend regression tests, and canonical safety documentation.

## Decisions

- `D-MAINT-CR032` - Phase 1 uses "Was office informed?" / "How was office informed?", hides WhatsApp from the communication-mode dropdown, hides Last Port, hides Weather ice-condition fields, and lays Latitude/Longitude side by side.
- Supersedes `D-MAINT-CR024` only for the current visibility/payload behavior of Last Port. The database column remains compatibility storage.
- Accepted default: existing database columns and existing stored values remain readable for backward compatibility; the current frontend no longer shows or sends the hidden fields for normal Phase 1 create/edit.
