**What & why**

Incident Next Actions Lessons Learned is being simplified by removing the user-facing "Why is this needed?" field. The same rationale value should also stop printing in the incident PDF so users see only the lesson details they are expected to enter and review.

**Tier + triggers**

Tier 2 - small behavior/output contract change. Triggers: changed Next Actions screen state and changed incident PDF layout contract.

**Domains touched**

Step 1 domains touched: Safety incident Phase 4, Lessons Learned presentation, incident PDF export.

Mini-interrogation:
- Should any database column or API payload change? No. Existing stored fields remain unchanged; the rationale field is no longer shown to users or printed in the PDF.
- Should existing lesson records be deleted or migrated? No. Existing data remains untouched.
- Should Lessons Learned still be available in Phase 4 and PDF? Yes. Only the "Why is this needed?" rationale wording/field is removed.
- Should workflow or approvals change? No. Phase navigation, save behavior, and PDF section selection remain unchanged.

**Decisions**

D-MAINT-CR028 records the current presentation rule: lesson entries do not expose or print rationale, while corrective/preventive rationale remains available.
