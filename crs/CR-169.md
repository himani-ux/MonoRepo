**What & why**
Clean up the Audit Observation closure UI so users choose either the dense four-part form or the guided three-step wizard instead of seeing both on the same page. This removes the confusing duplicated layout while preserving the same Observation closure API and saved fields.

**Tier + triggers**
Tier 2 - small feature / behavior change. Trigger: new/changed screen state for the existing Observation closure workflow.

**Domains touched**
Audit Observation closure: `SCR-AUD-6`, `FEAT-AUD-501`, `FEAT-AUD-502`, `FEAT-AUD-503`.
Audit finding detail navigation: `SCR-AUD-12`.

**Decisions**
Accepted default: match the existing NC closure navigation pattern by keeping `/audit/findings/:findingId/obs` as the dense Observation closure page and adding `/audit/findings/:findingId/obs/wizard` for the guided Observation wizard.
Accepted default: keep the same backend endpoints and payload fields; this is frontend route/layout separation only.
Accepted default: keep the wizard's existing three-step draft-save behavior and keep the dense page's existing Part A-D sections.
