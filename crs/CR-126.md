**What & why** - Clean up the slow Certs GET/list APIs by reducing list payload size, adding bounded tracked-item pagination, and removing avoidable per-row display-name lookups from list/dashboard serialization. Detail/download/export endpoints keep the full data needed for drill-down and evidence views, while list screens stop pulling heavyweight JSON fields or whole-fleet rows that are not needed for the visible table. The timing pass also exposed two broken read paths: Certs settings used stale VesselData column names and audit-log detail rejected uppercase SQL Server GUIDs returned by the list endpoint; both were corrected as part of the same performance verification.

**Tier + triggers** - Tier 2. Trigger: changed API list contract shape and frontend list-loading behavior for performance.
