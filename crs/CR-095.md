**What & why**

Fixed Chief Accounting Officer login/read access so the profile can open the VIMS dashboard, inspections, CARs, Safety incident/near miss/SOI/SCM screens, Certs screens, and dashboards without landing on a blank route loop. The previous grant added PSC form IDs only, but the frontend requires PSC view process IDs to render read-only PSC routes, and backend vessel filters needed an explicit fleet-wide read scope for this profile.

**Tier + triggers**

Tier 2 - small behavior/data change. Triggers: changed role permission behavior, changed local RBAC/profile data, and changed login vessel-scope behavior for one office profile.

**Domains touched**

Step 1 domains: authentication/login, RBAC/profile permissions, office vessel scope filtering, dashboard/list visibility, and local deployment data.

**Decisions**

No new SSOT decision. Accepted default: Chief Accounting Officer receives only read/navigation permissions, not create/edit/approve/delete/export process permissions. Accepted default: the profile gets `has_global_vessel_access = true` through code rather than `Mapping_CrewAssReviewers`, because that table has only one active PIC role slot per rank and using it would overwrite existing PIC mappings.
