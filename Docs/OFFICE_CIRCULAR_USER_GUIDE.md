OFFICE CIRCULAR USER GUIDE

This guide is written in simple language for office users.

1. Purpose

Use the Circular module to create, review, publish, track, and search:

- circulars
- alerts
- work instructions

This module is mainly used by office teams to send controlled information to vessels and crew.

2. Main screens you may see

- KSM Library: search and manage approved circulars
- Office User Panel: create a new circular, alert, or work instruction
- View All Notifications: admin-only full list of circular records
- View Your Notification: your own submitted items
- View Draft Notifications: drafts saved for later

3. KSM Library

This is the approved library screen.

You can use it to:

- search approved records
- filter and sort them
- download them
- check crew reading status
- send reminders

Search, filter, and sort tools

- Search title, SR No, hashtags...: find a record quickly
- Type filter: filter by document type
- Priority filter: filter by priority
- Sort options: change the order of the list
- Download CSV: download the library list
- Reset: remove search and filter values

Row actions you may see

- Title click: opens the full title if it is too long
- Download: downloads the attachment
- View Seen Crews: opens the crew read-status list
- Remind: sends a reminder to unread crew
- Supersede: marks an older record as replaced by a new one
- Delete: removes the record, if your role allows it

Seen Crews popup

When you open View Seen Crews, you may see:

- crew name
- rank
- vessel
- read or unread status
- reminder status

There is also a search field called:

- Search rank, vessel, crew name or crew ID...

4. Office User Panel

Use this page to create a new record.

The main card is called Create Circular / Alert / WI.

Main fields on the form

- Document Type: choose Circular, Alert, or Work Instruction
- Department: choose the department
- Scope: choose Internal or External
- Sub-category: choose the main category
- Second sub-category: choose the second category if needed
- Priority: choose the importance level
- Title: main heading
- Body / Instructions: the full message or instruction
- Hashtags: search tags
- Attachments: add up to 3 supporting PDF files. Each PDF must not exceed 50 MB.

Main buttons on the form

- Save Draft: saves your work for later
- Publish: moves the item toward final issue, based on your role
- Submit for Approval: sends the item for approval
- Show Pending Requests: opens pending approval records

5. Popups used during publish or approval

Select Vessels popup

This popup is used to choose which vessels should receive the item.

Buttons you may see

- Select All
- Cancel
- Confirm Approval

Select Ranks popup

This popup is used to choose which ranks should receive the item.

Buttons you may see

- Cancel
- Confirm

Comment popup

This popup is used during approval or rejection.

Buttons you may see

- Confirm Approve
- Confirm Reject

6. Approval Requests and Pending Approval Requests

The office panel also shows approval tables.

What you can do in these tables

- View: open the request details
- Approve: approve the request
- Reject: reject the request
- Open PDF: open the attached file
- Close: close the popup window

These tables help approvers manage records waiting for a decision.

7. My Notifications

Open View Your Notification to see the items linked to your account.

Status values you may see

- Pending
- Approved
- Rejected
- Deleted

Useful actions on this page

- Comment click: opens the full comment
- View Attachment: opens the attached file

8. Draft Notifications

Open View Draft Notifications to continue work saved earlier.

What you can do

- open a draft
- edit the draft
- delete the draft

Use this screen when the circular is not ready to send yet.

9. View All Notifications

This screen is mainly for admin users.

It shows all submitted circular records in one place.

Controls on this page

- Sort by: sort by Date Created, Serial Number, Type, Status, or Created By
- Order: choose Ascending or Descending
- Filter by Status: show All, Approved and Rejected, Approved Only, or Rejected Only
- Comment click: opens the full comment
- Download: downloads the attachment

10. Simple office circular flow

1. Open Office User Panel.
2. Fill the form.
3. Use Save Draft if the document is not ready yet.
4. Use Submit for Approval if approval is required.
5. Use Publish if your role allows direct publishing.
6. Choose vessels and ranks when the popups appear.
7. After approval, check the item in KSM Library.
8. Use View Seen Crews and Remind if crew have not read it.

11. Final note

If you do not see every action mentioned in this guide, it usually means:

- your login is not an admin or approver login
- the record is still in the wrong stage
- the item is already approved, rejected, or deleted
