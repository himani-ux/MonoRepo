4. **Audit Tests** — activity_events and audit_logs created
5. **Edge Case Tests** — Boundaries, nulls, empty strings

- Fixture files (conftest.py, fixture modules)

## Test Quality Standards

### Every Test Must Have:
1. **Docstring** citing PRD/VALIDATION_RULES/BACKEND_STRUCTURE reference
2. **Clear name** following `test_FEAT_xxx_scenario_expected` pattern
3. **Single assertion concept** (multiple asserts OK if testing same thing)
4. **Isolated** — no dependency on other tests
5. **Deterministic** — same result every run

### Every Test File Must Have:
1. **Module docstring** with PRD reference and generation date
2. **Organized classes** by test category (HappyPath, Validation, RBAC, Audit, EdgeCases)
3. **Fixtures** for common test data (in conftest.py or imported)

### Coverage Requirements Per Feature:
- [ ] Every acceptance criterion in PRD.md has ≥1 test
- [ ] Every validation rule in VALIDATION_RULES.md has ≥1 test
- [ ] Every role in RBAC matrix tested (success AND failure)
- [ ] activity_event creation tested
- [ ] audit_log creation tested (if applicable)
- [ ] At least 2 edge case tests

<anti_hallucination_rules>

## Read Before Writing
- Read the actual source code to understand what endpoints/functions exist
- Read PRD.md for exact acceptance criteria wording
- Read VALIDATION_RULES.md for exact validation rules
- Read BACKEND_STRUCTURE.md for exact API contracts and RBAC matrix
- Do NOT assume what the code does — verify by reading it

## Test What Exists
- Only test endpoints/functions that actually exist in the codebase
- Use the exact endpoint paths from BACKEND_STRUCTURE.md
- Use the exact field names from schemas
- Use the exact status codes documented

## Cite Everything
- Every test docstring must cite the source (PRD, VALIDATION_RULES, BACKEND_STRUCTURE)
- If you can't cite where a test requirement comes from, don't write the test

## Flag Gaps
- If code doesn't match PRD acceptance criteria, FLAG it:
  ```
  ⚠️ GAP DETECTED:
  PRD says: "MOU selection available for PSC inspections"
  Code has: No mou_id field in InspectionCreate schema
  Action: Flag for developer to fix, skip this test for now
  ```

- If validation rule in VALIDATION_RULES.md isn't implemented, FLAG it:
  ```
  ⚠️ VALIDATION GAP:
  VALIDATION_RULES says: port_place max 200 chars
  Code has: No max_length validation on port_place
  Action: Flag for developer to fix, write test anyway (will fail)
  ```
