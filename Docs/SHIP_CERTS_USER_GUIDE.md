SHIP CERTIFICATE USER GUIDE

This guide is written in simple language for ship users.

1. Purpose

Use the Certificates module on ship side to:

- view vessel certificates
- check certificate expiry status
- upload certificate PDFs
- open uploaded PDFs
- read office messages
- respond to office review messages
- print or share certificate status, if your role allows it

2. Important note

Some buttons appear only for Master or approved ship roles.

If you do not see a button, your login may not have permission for that action.

3. Simple meaning of common words

- Certificate: one certificate record for your vessel.
- Certificate file: PDF copy of the certificate.
- Vessel Certificates: full certificate list for your vessel.
- Class Status PDF: official class report uploaded by office.
- Messages from Office: review messages sent by office after checking class report.
- Mandatory coverage: percentage of mandatory certificates available for the vessel.
- Need attention: certificate items that need action.

4. Certificates screen

For ship users, the Certificates menu opens the vessel certificate list.

Top information:

- vessel name
- IMO
- flag
- class
- ship type
- current Master
- last class snapshot
- mandatory coverage

Top buttons:

- Vessel profile: opens vessel profile details.
- Open class status PDF: opens the latest class status PDF uploaded by office.
- Print certs status: creates PDF and Excel, if allowed.
- Share bundle: creates ZIP bundle, if allowed.

5. Messages from Office card

This card appears when office has sent class review messages.

Text you may see:

- Checking for office messages.
- No pending office messages.
- 1 message from office needs review.

Button:

- Open messages: opens the Messages from Office screen.

6. Summary cards

These cards show quick status.

- Certificates: total certificates in the vessel register.
- Need attention: certificates needing action.
- Certificates missing: records without uploaded PDFs.
- Class certificates: certificates checked against class report.

7. Filters

Use filters to find certificates quickly.

- Search: search by certificate name, number, or issuer.
- Status: filter by current, renewal due, urgent, expired, pending upload, or pending approval.
- Section: show one certificate section.
- Certificate type: show class certificates or other certificates.
- Certificate file: show missing files or attached files.

8. Certificate section list

Certificates are grouped by section.

Each section shows:

- section name
- number of active certificates
- status badges

Desktop table columns:

- Certificate
- Cert number
- Issued by
- Issue date
- Expiry date
- Status
- Valid for
- Action

Mobile card fields:

- certificate name
- cert number
- issued by
- expiry
- valid for
- status
- action buttons

9. Action buttons in certificate list

Upload icon:

- Opens the certificate detail page.
- Use this to upload or update the certificate.

Eye icon:

- Opens the uploaded certificate PDF.

Disabled eye icon:

- No PDF is uploaded yet.

10. Certificate Detail screen

Open this screen from a certificate row or the upload icon.

Main areas:

- Header
- Certificate details
- Certificate file
- Review and history

Header shows:

- certificate name
- vessel
- certificate number
- status
- approval state
- missing PDF warning, if applicable

Header button:

- Back to vessel: returns to vessel certificate list.

11. Certificate details card

This card shows certificate information.

You can see:

- certificate number
- issuing authority
- place of issue
- issue date
- expiry date
- valid for
- renewal starts
- renewal deadline
- next due

Buttons:

- Edit: opens editable fields.
- Close edit: closes editing.
- Save details: saves changes.
- Cancel: cancels editing.

Edit fields:

- Certificate number
- Issuing authority
- Place of issue
- Issue date
- Expiry date
- Reason

12. Certificate file card

This card shows the uploaded PDF.

If a PDF is present:

- file name is shown
- upload date is shown
- uploaded by is shown
- file size is shown

Buttons:

- View PDF: opens the certificate PDF.
- Upload certificate: uploads a new certificate PDF.
- Read PDF again: reads the same PDF again if details were not captured correctly.
- Remove file: removes the active PDF after a reason is entered.

If no PDF is present:

- screen shows No active certificate file.
- upload a PDF using Upload certificate.

13. Upload certificate window

Use this window to upload a certificate PDF.

Fields:

- Certificate file: select PDF file.
- Reason: short reason, for example Uploading renewed certificate.

Buttons:

- Cancel: closes the window.
- Upload certificate: uploads the PDF.

What to upload here:

- Upload the actual certificate PDF.
- Do not upload the class status report here.
- Do not upload screenshots unless the office has allowed it.

14. Read PDF again

Use this button when:

- the PDF was uploaded
- details did not update correctly
- the PDF needs to be read again

The system reads the same uploaded PDF again.

15. Remove file window

Use this only if the wrong PDF was uploaded.

Fields:

- Reason: explain why the PDF is being removed.

Buttons:

- Cancel: closes the window.
- Remove file: removes the active PDF.

16. Version history

This section shows previous uploaded PDF files.

Status labels:

- Active: current certificate PDF.
- Superseded: older PDF version.

17. Review and history card

This card shows approval status and activity.

You can see:

- approval status
- submitted by
- submitted on
- approved by
- approved on
- times rejected
- draft expiry date
- approval history
- recent activity

Buttons you may see:

- Submit for approval: sends the certificate for review.
- Approve: approves a pending certificate, usually Master role.
- Reject: rejects a pending certificate and needs a note.

Review note:

- Add a short note before submitting, approving, or rejecting.

18. Messages from Office screen

Open this from the Messages from Office card.

Purpose:

- view items office wants the vessel to check
- open the class report PDF
- open the linked certificate
- reply to office by marking the item reviewed

Top option:

- Show reviewed messages: also shows messages already completed.

Message status:

- Needs review: Master needs to check it.
- Reviewed: Master has already marked it reviewed.

Buttons inside a message:

- Open class status PDF: opens the class report uploaded by office.
- Open certificate: opens the linked certificate record.
- Mark reviewed: sends Master review back to office.

Fields:

- Office note: message from office.
- Review note: your reply to office.

Simple message flow:

1. Open Messages from Office.
2. Read the office note.
3. Open class status PDF if needed.
4. Open certificate if linked.
5. Type a review note.
6. Click Mark reviewed.

19. Class Status PDF

The class status PDF is uploaded by office.

Ship users can open it from:

- Vessel Certificates screen, if latest class PDF exists.
- Messages from Office screen, if the message has a linked class PDF.

Button:

- Open class status PDF

If the PDF does not open:

- allow pop-ups for the site
- try again
- inform office if it still fails

20. Vessel Profile screen

This screen shows vessel profile details.

You may see:

- lifecycle
- ship type
- pending disposal
- sale bundle

Button:

- Back to certificates: returns to vessel certificate list.

Most lifecycle actions are office restricted.

21. Print certs status screen

This screen appears only if your role can print.

Use it to create PDF and Excel for vessel certificate status.

Fields:

- Vessel: selected automatically.
- Certificate sections: choose All sections or one section.

Buttons:

- Print history: opens old generated files.
- Share bundle: opens share bundle screen.
- Generate PDF and Excel: creates print files.
- Download PDF: downloads PDF.
- Download Excel: downloads Excel.
- Download ZIP: downloads ZIP if available.

22. Share Bundle screen

This screen appears only if your role can create share bundle.

Use it to create a ZIP file for selected certificate sections.

Fields:

- Vessel: selected automatically.
- Certificate sections: choose one or more sections.
- Recipient name: name for the bundle.
- Recipient email: email address for sending the bundle.

Buttons:

- Select all: selects all visible sections.
- Clear all: removes selected sections.
- Generate ZIP bundle: creates the ZIP.
- Download ZIP: downloads the ZIP.
- Download PDF: downloads PDF if available.
- Download Excel: downloads Excel if available.

23. Print History screen

Use this screen to download previously generated files.

Buttons:

- Print certs status: go back to print screen.
- Download PDF
- Download Excel
- Download ZIP

24. Common ship workflows

Upload or renew a certificate:

1. Open Certificates.
2. Search or filter the certificate.
3. Click the upload icon.
4. Click Upload certificate.
5. Select the certificate PDF.
6. Add reason.
7. Click Upload certificate.
8. Check details.
9. Click Submit for approval if required.

View a certificate PDF:

1. Open Certificates.
2. Find the certificate.
3. Click the eye icon.
4. If the eye icon is disabled, PDF is not uploaded.

Reply to office message:

1. Open Messages from Office.
2. Read the office note.
3. Open class status PDF or certificate if needed.
4. Add review note.
5. Click Mark reviewed.

Print vessel certificate status:

1. Open Vessel Certificates.
2. Click Print certs status.
3. Choose certificate section.
4. Click Generate PDF and Excel.
5. Download the file.

Create share bundle:

1. Open Vessel Certificates.
2. Click Share bundle.
3. Select certificate sections.
4. Enter recipient name and email if needed.
5. Click Generate ZIP bundle.
6. Download the ZIP.
