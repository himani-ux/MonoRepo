OFFICE CERTIFICATE USER GUIDE

This guide is written in simple language for office users.

1. Purpose

Use the Certificates module to:

- view vessel certificate status
- upload and review certificate PDFs
- upload class status PDFs
- compare class report data with VIMS records
- send review messages to vessel Master
- print certificate status
- create share bundles
- manage certificate catalog rows
- onboard vessel certificates
- check audit history and settings

2. Important note

Some screens and buttons appear only for certain roles.

If you do not see a button, your login may not have access to that action.

3. Simple meaning of common words

- Certificate: one vessel certificate record.
- Certificate file: the PDF copy of a certificate.
- Vessel Certificates: the full certificate register for one vessel.
- Class Status PDF: official Class Status or Vessel Status report from NK, KR, or BV.
- Class Reconciliation: system comparison between VIMS certificates and the Class Status PDF.
- Condition of Class: class condition found in the class report, with summary and due date.
- Mandatory coverage: percentage of mandatory certificates available for the vessel.
- Share Bundle: ZIP file prepared for sharing vessel certificate status.
- Print certs status: PDF and Excel output for vessel certificate status.

4. Certificates home screen

This is the first Certificates page for office users.

Main buttons:

- Open catalog: opens the certificate catalog setup.
- Class reconciliation: opens the class status PDF upload and review screen.
- Open vessel certificates: opens one vessel certificate register.
- Pending approvals: opens uploaded certificates waiting for approval.

Main cards:

- Certificate Register: main entry area for certificate work.
- Class Reconciliation: quick link to class status PDF review.
- Pending approval: shows certificate uploads waiting for review.
- Vessel Certificates: shows onboarded vessels and certificate counts.
- Cadence heartbeat: shows whether scheduled certificate checks are running.
- Bouncing email delivery: shows users whose certificate emails are failing.
- High-volume print activity: shows unusual print activity.

5. Vessel Certificates screen

Open this screen from the vessel list.

This screen shows all certificates for one vessel.

Top information:

- vessel name
- IMO
- flag
- class
- ship type
- current Master
- last class snapshot
- mandatory coverage

Top buttons:

- Vessel profile: opens lifecycle details for the vessel.
- Open class status PDF: opens the latest uploaded class status PDF.
- Print certs status: creates PDF and Excel for this vessel.
- Share bundle: creates a ZIP bundle for this vessel.

Summary cards:

- Certificates: total certificates for the vessel.
- Need attention: items needing action.
- Certificates missing: certificates without PDF files.
- Class certificates: certificates tracked against class report.

Filters:

- Search: find certificate by name, number, or issuer.
- Status: filter by current, renewal due, urgent, expired, pending upload, or pending approval.
- Section: filter by certificate section.
- Certificate type: show class certificates or other certificates.
- Certificate file: show missing or attached files.

Certificate section table:

- Certificate: certificate name.
- Cert number: certificate number.
- Issued by: issuing authority.
- Issue date: certificate issue date.
- Expiry date: certificate expiry date.
- Status: current status.
- Valid for: validity type or duration.
- Action: quick buttons.

Action buttons:

- Upload icon: opens the certificate detail page.
- Eye icon: opens the certificate PDF.
- Disabled eye icon: no PDF has been uploaded yet.

6. Certificate Detail screen

Open this screen by clicking a certificate or the upload icon.

Main areas:

- Header: certificate name, vessel, certificate number, and status.
- Certificate details: certificate number, issuing authority, place of issue, dates, and validity.
- Certificate file: current PDF and file actions.
- Review and history: approval status, review note, and activity history.

Certificate details buttons:

- Edit: allows correction of certificate details.
- Close edit: closes the edit form.
- Save details: saves corrected details.
- Cancel: cancels the edit.
- Back to vessel: returns to vessel certificate list.

Certificate file buttons:

- View PDF: opens the current certificate PDF.
- Upload certificate: upload a certificate PDF.
- Read PDF again: asks the system to read the uploaded PDF again.
- Remove file: removes the active certificate file after giving a reason.

Upload certificate window:

- Certificate file: select the certificate PDF.
- Reason: short reason for upload.
- Cancel: closes the window.
- Upload certificate: uploads the file.

Remove file window:

- Reason: explain why the file is being removed.
- Cancel: closes the window.
- Remove file: removes the active PDF.

Review and history buttons:

- Submit for approval: sends uploaded certificate for review.
- Approve: approves the submitted certificate.
- Reject: rejects the certificate and requires a review note.

8. Class Reconciliation screen

Use this screen to upload and review Class Status PDFs.

Reconciliation runs table:

- Vessel: vessel name and IMO.
- Class: class society such as NK, KR, or BV.
- Run: reading status and run time.
- Findings: summary of matched and review items.
- Printed On: report printed date from the PDF.
- Action: opens the review page.

Buttons:

- Review: opens the reconciliation review page.
- Upload snapshot: uploads a new Class Status PDF.
- Reparse: reads an uploaded Class Status PDF again.

Upload class snapshot card:

- Vessel: choose vessel name from dropdown.
- Class: choose NK, KR, or BV.
- Report date from PDF: enter only if the system cannot read the printed date.
- Class Status PDF: upload the official class status report.
- Upload snapshot: uploads and starts reading the report.

What to upload in Class Status PDF:

- Upload the latest official Class Status or Vessel Status PDF from the class society portal.
- Use NK, KR, or BV report as applicable.
- Do not upload an individual certificate PDF here.
- Do not upload screenshots.
- The report printed date must come from the PDF.

Recent snapshots card:

- Shows recently uploaded class status PDFs.
- Shows read status.
- Reparse reads the same PDF again if the first reading was not correct.

9. Reconciliation Review page

Open this page from the Review button.

Top area:

- vessel name
- class society
- printed date
- number of matched items
- number of findings

Top button:

- Open class report PDF: opens the uploaded class status PDF.

Left list:

- Shows items needing review.
- Click an item to view details.
- Match means VIMS and class report match.
- Needs review means office must check it.
- Done means already reviewed.

VIMS certificate record card:

- Shows the matching VIMS certificate.
- Open VIMS certificate opens the certificate detail page.

Class report item card:

- Shows details found in the class report.
- For Condition of Class, it shows only Summary and Due date.

Review action card:

- Review note: enter office review note.
- Notify Master: sends the message to vessel side.
- Ask vessel to update: opens the linked certificate so the vessel can update it.
- Link to VIMS certificate type: links an unmatched class report item to a VIMS certificate type.
- Mark reviewed: marks the item reviewed by office without sending it to Master.

What Notify Master does:

- Sends the selected review item to vessel side.
- Master sees it in Messages from Office.
- Master can open the class status PDF, open the certificate, add a note, and mark it reviewed.

10. Messages sent to Master

Office sends messages from the Reconciliation Review page.

Use Notify Master when:

- vessel action is needed
- Master should check a condition or certificate
- office wants a note from vessel side

Use Mark reviewed when:

- office has checked the item
- no vessel action is needed

15. Catalog Admin screen

Use this screen to manage certificate master list.

Catalog add, edit, and deprecate buttons are available to DPA, SEQ Manager, Marine Superintendent, Technical Superintendent, Admin, Super Admin, and System Admin users when their profile includes the catalog edit permission.

Left side:

- All sections: show all catalog rows.
- Section names: filter rows by section.

Top filters:

- Filter catalog: search by code or name.
- Ship type: filter by ship type.

Main buttons:

- Add row: create a new catalog row.
- Bulk soft-delete: mark selected rows inactive.
- Save row: saves a new row.
- Save changes: saves edits to an existing row.
- Deprecate row: marks one catalog row inactive.
- Cancel: closes the current action.

Catalog table columns:

- Select: checkbox for bulk action.
- Code: catalog code.
- Name: certificate name.
- Validity: validity type.
- Ship types: applicable ship types.
- Status: active or inactive.

Add row and edit row fields:

- Canonical code: unique certificate code.
- Section ID: section number.
- Display name: certificate name shown to users.
- Short name: shorter label.
- Print section label: section heading used in print output.
- Validity type: certificate validity type.
- Cadence months: renewal cycle in months.
- Issuing authority type: flag, class, maker, company, or other authority.
- Submission scope: who can submit this certificate.
- Parent row: parent certificate if applicable.
- Applicable ship types: ship types where this row applies.
- Applicability mode: where this row applies.
- Specific vessels: choose vessel names if using specific vessel mode.
- Class tracked: include this row in class report comparison.
- Mandatory for all vessels: count this row in mandatory coverage.
- Dynamic child TrackedItems: allows child items under a parent row.
- PMS component ID: optional PMS reference.
- Reason: why this catalog change is made.

17. Onboarding Wizard screen

This screen has seven steps.

Step 1 - Vessel selection:

- Vessel is selected for onboarding.

Step 2 - Vessel profile:

- Anniversary date
- Ship type
- Marine Supt user ID
- Technical Manager user ID
- Save and continue

Step 3 - Cert PDF batch ingest:

- Add existing PDF blob IDs if used.
- Create batch creates a PDF batch.
- Review batch opens gap-fill review.

Step 4 - Class status upload:

- Keeps class status upload step visible.

Step 5 - Reconciliation review:

- Used after class report reading is available.

Step 6 - Coverage gate:

- Shows mandatory coverage.
- Shows missing mandatory certificates.
- Save override reason allows approved exception.

Step 7 - FM sign-off:

- Shows vessel, coverage, batches, and anniversary.
- Sign off - vessel goes live completes onboarding.

Other buttons:

- Reset onboarding: cancels onboarding before sign-off.
- Confirm reset: confirms reset after reason is entered.

22. Simple office workflow

For normal certificate PDF:

1. Open Certificates.
2. Open vessel certificates.
3. Open certificate detail.
4. Upload certificate PDF.
5. Review extracted details.
6. Submit, approve, or reject as per role.

For class status PDF:

1. Open Class reconciliation.
2. Select vessel.
3. Select class.
4. Upload Class Status PDF.
5. Open Review.
6. Check each item.
7. Notify Master if vessel action is needed.
8. Mark reviewed if office action is complete.

For print or sharing:

1. Open vessel certificates.
2. Click Print certs status or Share bundle.
3. Select certificate sections.
4. Generate file.
5. Download PDF, Excel, or ZIP.
