SHIP INSPECTION USER GUIDE

This guide is written in simple language for ship users.

1. Purpose

Use the Inspection module on ship side to:

- create inspection records
- add deficiencies
- work on CARs
- follow office comments and notifications
- sync your work when internet is available

2. Simple meaning of common words

- Inspection: the main record of an inspection visit
- Deficiency: a problem found during inspection
- CAR: Corrective Action Report. This is the action record used to fix a deficiency
- PV: Physical Verification. This is a later physical check after closure

3. Main screens you may see

- Dashboard: quick view of vessel inspection status
- Inspections: list of inspections
- Deficiencies: deficiency workflow tracking
- CARs: corrective action work
- Notifications: alerts and updates
- Sync: offline data and sync status
- Reports: extra reporting tools for some ship roles
- Settings: read-only company logo view, if available

4. Dashboard

The Dashboard is the summary page.

You can use it to:

- see important counts
- check repeated issues
- open related inspection or CAR work faster

This page helps you understand what needs attention first.

5. Inspections screen

Open Inspections to see all inspection records for your vessel.

Main filters and buttons on this screen

- All Types: filter by PSC, RightShip, or Audit
- All Statuses: filter by Open or Closed
- Search vessel, port...: find a record quickly
- Detentions: show detention inspections only
- Clear: remove all filters
- Export Excel: download the list
- New Inspection: create a new inspection draft, if your login allows it

How to create an inspection

1. Click New Inspection.
2. Fill the required details.
3. Attach the report file if needed.
4. Click Create Draft.

6. Inspection detail screen

Open an inspection to see the full record.

This page shows:

- inspection details
- deficiency list
- related CAR information
- action buttons

Buttons you may see

- Add Deficiency: add a deficiency to the inspection, if your role allows it
- Edit Inspection: change the inspection details
- Download All CARs: download related CARs
- Register Follow-up: used for PSC follow-up, usually by Master only

Important note

When a deficiency is added, the system automatically creates a CAR.

7. Deficiencies screen

Open Deficiencies to track the progress of problems found during inspection.

Main filters and buttons on this screen

- All Statuses: show all stages
- Awaiting Review: show records waiting for review
- Previous: go to the previous page
- Next: go to the next page

Status names you may see

- Allotted: work has been assigned
- In Progress: work is being done
- Pending CE Review: waiting for Chief Engineer review
- Pending Master Review: waiting for Master review
- Submitted to PIC: sent to office reviewer
- PIC Review: office review is in progress
- Submitted to DPA: waiting for final closure
- Closed: completed
- Returned for Rework: sent back for correction

How to use this screen

1. Open a deficiency card.
2. Check the current stage.
3. Complete the next required work.
4. Move to the linked CAR if needed.

8. CARs screen

Open CARs to work on deficiency correction.

Main filters and buttons on this screen

- All Statuses: filter by CAR stage
- Search CAR number, vessel...: find a CAR quickly
- PV Due: show CARs that need physical verification attention
- Overdue: show overdue CARs
- Clear: remove filters

9. CAR detail screen

Open a CAR to do the actual correction work.

This page can include:

- root cause
- action plan
- evidence files
- review comments
- physical verification details

Buttons you may see

- Edit: open the CAR for editing
- Workflow action buttons: move the CAR to the next stage
- Evidence upload action: add supporting files

Simple ship-side CAR flow

1. Open the CAR.
2. Add or update the corrective action details.
3. Upload required evidence.
4. Use the available workflow button to send it to the next review stage.
5. If office sends it back, correct it and submit again.

10. Notifications screen

Open Notifications to see new updates from the system.

What you will see

- notifications grouped as Today, Yesterday, and Earlier
- related inspection and CAR updates

Buttons on this screen

- Mark All Read: marks all unread messages as read
- Load more: shows older notifications

11. Sync screen

This is one of the most important screens for ship users.

Use Sync to check:

- whether you are online or offline
- last sync time
- pending changes waiting to upload
- storage usage
- sync conflicts

Buttons on this screen

- Sync Now: uploads and downloads data
- Clear Old Data: removes local cached data

Important caution

Do not use Clear Old Data unless you are sure it is needed. Local cached data will be removed.

12. Reports screen

Some ship roles may also see Reports.

This screen can include:

- checklist preview
- checklist export
- prediction

Buttons you may see

- Preview
- Export Checklist
- Run Prediction

13. Settings screen

If Settings is visible on ship side, it is mainly a view page for the company logo used on PDF reports.

Ship users do not normally upload or replace the logo.

14. Simple daily flow for ship users

1. Open Inspections and create or update the inspection record.
2. Add deficiencies if any issues were found.
3. Open CARs and complete the correction work.
4. Check Notifications for review comments or returns.
5. Use Sync Now when internet is available.

15. Final note

If a button is missing, it usually means:

- your login does not have that permission
- the record is not yet at the correct stage
- that action belongs to office side
