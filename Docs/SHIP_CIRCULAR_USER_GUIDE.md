SHIP CIRCULAR USER GUIDE

This guide is written in simple language for ship users.

1. Purpose

Use the Circular module on ship side to:

- read company circulars
- read alerts
- read work instructions
- download attached files
- acknowledge that you have read the document

2. Main screens in this module

- KSM Library: main list of circulars, alerts, and work instructions
- PDF Viewer: screen used to read the attached PDF and acknowledge it

3. KSM Library

This is the main ship-side circular screen.

It shows the list of published records.

4. Filters and buttons on the library screen

- Search titles, tags...: find a circular quickly
- SEQ: show SEQ scope items
- Technical: show Technical scope items
- Alert: show alerts only
- Circular: show circulars only
- Work Instruction: show work instructions only
- Critical: show critical items
- High: show high-priority items
- Medium: show medium-priority items
- Low: show low-priority items
- Only unread: show only documents not yet acknowledged
- Download: download the current list

5. Buttons on each circular row

- Open details: opens the detail panel for that circular
- View: opens the PDF viewer
- Download: downloads the file

6. Detail panel

When you click Open details, a detail panel opens.

This panel can show:

- document ID
- published date
- scope
- tags
- reminder status
- crew reading status

Buttons you may see inside the detail panel

- Open PDF: opens the attached PDF
- View Crew Status: shows who has read it
- Hide Crew: hides the crew status list
- Remind: sends a reminder to unread crew, if your login allows it
- Reminded: shows that a reminder has already been sent

7. Crew status view

When the crew status list is open, you can see:

- crew name
- rank
- read status
- unread status
- reminder status

This helps senior ship users follow up with unread crew.

8. PDF Viewer

Open the PDF in the PDF Viewer screen.

Buttons on this page

- Back to List: returns to the library list
- Download: downloads the file
- Read and Acknowledge: confirms that you have read the document

Important note

The Read and Acknowledge button appears after the PDF has been read fully on the screen.

9. Simple ship circular flow

1. Open Circular.
2. Use the filters if needed.
3. Click Open details to understand the document.
4. Click Open PDF or View.
5. Read the document fully.
6. Click Read and Acknowledge.

10. Final note

If you are responsible for follow-up on board, use:

- Only unread to find unread items quickly
- View Crew Status to see who is pending
- Remind to push unread crew to read the document
