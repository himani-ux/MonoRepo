OFFICE INSPECTION USER GUIDE

This guide is written in simple language for office users.

1. Purpose

Use the Inspection module from office side to:

- review inspection work
- monitor vessel performance
- track deficiencies
- manage CARs
- check reports
- read notifications
- manage the company logo used in PDF reports

2. Simple meaning of common words

- Inspection: the main record of a PSC, RightShip, or Audit visit
- Deficiency: a problem found during an inspection
- CAR: Corrective Action Report. This is the action record used to fix a deficiency
- PV: Physical Verification. This is the physical follow-up check after closure

3. Main screens you may see

- Dashboard: summary of inspection and CAR activity
- Inspections: list of inspection records
- Deficiencies: deficiency workflow and review
- CARs: corrective action records
- Reports: checklist builder, OpenSource import, and prediction
- Notifications: updates and alerts
- Settings: company logo for PDF reports
- Sync: sync and conflict screen, if your login has access

4. Dashboard

The Dashboard is the summary screen.

You can use it to:

- see key numbers quickly
- check repeat deficiencies
- review recent inspection activity
- move into related records by opening cards or lists

Office users can also switch vessel context and review one vessel at a time.

5. Inspections screen

Open Inspections to see the full inspection list.

Main filters and buttons on this screen

- All Types: filter by PSC, RightShip, or Audit
- All Statuses: filter by Open or Closed
- Search vessel, port...: find inspections quickly
- Detentions: show detention cases only
- Clear: remove the filters
- Export Excel: download the list in Excel
- New Inspection: create a new inspection draft

How to create a new inspection

1. Click New Inspection.
2. Fill the required details.
3. Add supporting details such as authority, inspector name, reference number, and report file if needed.
4. Click Create Draft.

If you try to leave with unsaved changes, the screen may ask:

- Discard changes?
- Discard
- Keep editing

6. Inspection detail screen

Open an inspection to see the full record.

This page usually shows:

- inspection summary
- deficiency list
- linked CAR information
- action buttons

Buttons you may see on this screen

- Add Deficiency: add a new deficiency to the inspection, if your role allows it
- Edit Inspection: change the inspection details
- Edit (Office Assist): help complete or correct the inspection from office side
- Download All CARs: download all related CARs
- Register Follow-up: used only in allowed PSC follow-up cases
- Delete Inspection: remove the inspection if it was created by mistake

Important note

If a deficiency is added to an inspection, the system automatically creates a CAR for it.

7. Deficiencies screen

Open Deficiencies to follow the deficiency workflow.

Main filters and buttons on this screen

- All Statuses: shows all deficiency stages
- Awaiting Review: shows records waiting for review
- Previous: go to the previous page
- Next: go to the next page

Status names you may see

- Allotted: work has been assigned
- In Progress: work is being done
- Pending CE Review: waiting for Chief Engineer review
- Pending Master Review: waiting for Master review
- Submitted to PIC: sent to office reviewer
- PIC Review: office review is in progress
- Submitted to DPA: waiting for final office closure
- Closed: completed
- Returned for Rework: sent back for correction

Simple way to use this screen

1. Filter the list if needed.
2. Open a deficiency card.
3. Review the details and current stage.
4. Take the next action if your role allows it.

8. CARs screen

Open CARs to manage corrective action reports.

Main filters and buttons on this screen

- All Statuses: filter by CAR stage
- Search CAR number, vessel...: find a CAR quickly
- PV Due: show items needing physical verification attention
- Overdue: show overdue CARs
- Clear: remove the filters

There is no New CAR button here because the system creates CARs automatically from deficiencies.

9. CAR detail screen

Open a CAR to review the full action record.

This page can include:

- root cause details
- evidence files
- action progress
- review comments
- physical verification section

Buttons you may see on a CAR

- Edit: open the CAR for editing
- Edit CAR: same purpose, depending on where you open it from
- Download (External): download the external CAR format
- Download (Internal): download the internal CAR format
- Workflow action buttons: move the CAR to the next stage
- Create PV: create a physical verification after closure
- Close PV: close the physical verification after the visit

Simple office-side use

1. Open the CAR.
2. Review root cause, action plan, and evidence.
3. Use the available workflow button for the next step.
4. If needed, return it for rework.
5. Close it when all work is complete.

10. Reports screen

Open Reports to use the reporting tools.

Main areas on this page

- A) Import OpenSource Excel (monthly): upload the monthly OpenSource Excel file
- B) Checklist Builder: build and export a checklist
- C) Prediction: view likely risk areas based on selected conditions

Buttons you may see on this page

- Import OpenSource: upload the source Excel file
- Preview: show checklist data before export
- Export Checklist: download the checklist
- Run Prediction: run the prediction view

11. Notifications screen

Open Notifications to see alerts and updates.

What you will see

- notifications grouped as Today, Yesterday, and Earlier
- newest records first

Buttons on this screen

- Mark All Read: marks all unread notifications as read
- Load more: shows older notifications

12. Settings screen

Open Settings to manage the company logo used in PDF reports.

What you can do here

- view the current logo
- upload a new logo
- replace the existing logo

Buttons on this screen

- Upload Logo: add the first logo
- Replace Logo: change the existing logo

File rules

- PNG or JPG only
- maximum size 2 MB

13. Sync screen

If your login has access to Sync, you can use it to check:

- connection status
- last sync time
- pending changes
- conflicts
- storage usage

Buttons on this screen

- Sync Now: starts a sync immediately
- Clear Old Data: removes local cached data

Use Clear Old Data carefully. It removes local cached data and you will need to sync again.

14. Simple daily flow for office users

1. Open Dashboard and check which vessel or item needs attention.
2. Open Inspections, Deficiencies, or CARs.
3. Review the record and move it to the next stage if needed.
4. Check Notifications for new actions.
5. Use Reports when you need export or planning support.
6. Use Settings only when the company logo needs to be changed.

15. Final note

If you do not see a button mentioned in this guide, it usually means:

- your role does not have that permission
- the record is not yet in the correct stage
- the action belongs to vessel side, not office side
