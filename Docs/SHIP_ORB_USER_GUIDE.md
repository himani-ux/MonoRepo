SHIP ORB USER GUIDE

This guide is written in simple language for ship users.

1. Purpose

Use the ORB module to manage the ship's electronic Oil Record Book.

You can use it to:

- enter ORB records
- review pending entries
- see approved, rejected, and deleted entries
- save approved records as PDF
- download master-signed PDFs
- open the guideline documents

2. Simple meaning of common words

- ORB: Oil Record Book
- Entry: one ORB record
- Pending: waiting for approval
- Approved: accepted
- Rejected: not accepted
- Deleted: removed from normal active view

3. Main screens in this module

- Dashboard: main working screen for ORB entry and review
- Approved Entries: final approved ORB entries
- Rejected Entries: entries that were rejected
- Deleted Entries: entries that were deleted
- Master Signed PDFs: PDF archive
- Guidelines: ORB guidance documents

Some users may also see an extra page called All Non-Deleted ORB Entries.

4. Dashboard

The Dashboard is the main ORB working screen.

It can show:

- the ORB entry form
- a table under the form for entries you can still manage
- report filter and report view
- pending entries waiting for approval
- approved entries preview

5. ORB entry form

The form starts with:

- Entry Date and Time
- Select Code

ORB codes used in this system

- A: tank cleaning and ballasting
- B: discharge of dirty ballast or tank washings
- C: collection, transfer, or disposal of sludge
- D: bilge water disposal
- F: condition of oil filtering equipment
- G: accidental or exceptional discharges of oil
- H: bunkering details
- I: additional remarks and operational notes

Main button on the entry form

- Save Draft: saves the ORB entry

Important note about Code F

If you save a Code F entry, the system will ask you to add a mandatory Code I entry before the save is completed.

6. Table below the entry form

Below the form, the screen can show a table called Your Drafts.

This table can include these buttons:

- Edit: opens the entry for changes
- Delete: deletes the entry

Important note

In the current workflow, a saved entry goes into the pending review flow used by reviewer screens.

7. Pending Crew Entries

Senior users may see a card called Pending Crew Entries.

This card is used to review pending entries.

Buttons on this card

- Approve: accepts the entry
- Reject: rejects the entry

8. Approved Logbook Entries Preview

This card shows approved entries before PDF save.

Button on this card

- Save as PDF: saves approved entries as PDF, if your login allows it

9. Report filter and report view

Some users may see the ORB report area.

Buttons and options here

- This Month: shows this month's report
- Last Month: shows last month's report
- Last 6 Months: shows the last 6 months
- Last Year: shows the last year
- Last 3 Years: shows the last 3 years
- Filter Report: loads the report
- Close Report: closes the report view

10. Approved Entries page

Open Approved Entries to see approved ORB records.

Button on this page

- Refresh: reloads the latest approved entries

11. Rejected Entries page

Open Rejected Entries to see rejected records.

Button on this page

- Refresh: reloads the latest rejected entries

12. Deleted Entries page

Open Deleted Entries to see deleted records.

Button on this page

- Refresh: reloads the latest deleted entries

13. Master Signed PDFs

Open Master Signed PDFs to see the PDF archive.

What you will see

- PDF title
- description
- created by
- created date and time

Buttons on this page

- Download: downloads the PDF
- Previous: opens the previous archive page
- Next: opens the next archive page

14. Guidelines

Open Guidelines to open the help documents.

You may see these links:

- ORB Correct Entries Guidelines
- Software Guidelines

Click a link to open or download the guideline PDF.

15. Simple ORB flow

1. Open Dashboard.
2. Fill Entry Date and Time.
3. Choose the correct Code.
4. Fill the code details.
5. Click Save Draft.
6. If needed, edit or delete the saved entry.
7. Senior users review Pending Crew Entries.
8. Approved entries can later be saved as PDF.
9. Use Master Signed PDFs when you need old signed PDF records.

16. Final note

If you do not see every button in this guide, it usually means:

- your login does not have that level of ORB access
- the entry is not in the correct stage yet
- the action belongs to reviewer level, not data-entry level
